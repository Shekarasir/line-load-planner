Sync with your team

Your work is now saved automatically in this browser as you go — closing or reopening this tab won't lose anything. The steps below are only needed to share data with teammates: export a file, drop it in your shared OneDrive folder, and others import it.

1 · I made changes

Made an entry — a new order, a line allocation, today's achieved volume? Save it and share it.

⚠️ In the Save box, the filename must be exactly line-load-data.json — if Chrome suggests "line-load-data (1).json", delete the "(1)" and click Save, then choose Replace when asked. Numbered copies won't be found by "Load latest data."

This downloads line-load-data.json. Move that file into your shared OneDrive folder (D:\OneDrive\ProductionPlanner) so it reaches everyone.

2 · Get the latest

Before you start work, pull in whatever the team has already saved.

Pick the line-load-data.json file from your shared OneDrive folder. This replaces what's on your screen with the shared version.

⚡ Auto-Sync to a shared file (recommended)

Connect once to a single shared file on your network drive — after that, every change saves and loads automatically, no Save/Load buttons needed. Works in Chrome and Edge.

Not connected

First time only: one person should first use "💾 Save my changes" below to create line-load-data.json in the shared network folder. After that, everyone — including that person — clicks Connect to shared file… above and selects that same file, once. From then on it's fully automatic for them.

Good habit

Load latest → make your changes → Save. If two people edit at the same time without syncing first, whoever saves last wins — so a quick Load before you start keeps everyone's work from getting overwritten by accident.

Factory Configuration

Lines, capacity, and machines are now managed per factory — see the Factories tab. This panel shows your combined total across every factory.

Category Factors

A line's daily capacity is divided by this factor for the category being produced — order quantity itself always stays in real pieces. E.g. a 1000 BH/day line produces 1000 Basic pcs/day, but only 1000 ÷ 1.5 = 666.7 Medium pcs/day, since each Medium piece takes longer. Edit these if your ratios differ.

OneDrive Backend

Data is stored as a single JSON file in your OneDrive App Folder. This requires a free, one-time Azure app registration to get a Client ID — Microsoft's own sign-in is what grants this app permission to read/write that folder; there's no separate password for the app itself.

How to get a Client ID (2 minutes, free)
  1. Go to portal.azure.com → Azure Active Directory → App registrations → New registration.
  2. Name it anything (e.g. "Line Load Planner"). Under "Supported account types" choose "Accounts in any organizational directory and personal Microsoft accounts".
  3. Under Redirect URI, choose platform Single-page application (SPA) and enter the URL/file location this app is opened from.
  4. After creation, go to API permissions → Add a permission → Microsoft Graph → Delegated → search Files.ReadWrite.AppFolder → Add.
  5. Copy the "Application (client) ID" from the Overview page and paste it above.
